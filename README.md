# Auto-Tech Content Pipeline (Autopilot AI)

Pipeline automatizado para la creación, curación y publicación de contenido educativo de tecnología (Cloud, Datos, AI y Arquitectura) utilizando agentes de IA y fuentes oficiales (AWS, Azure, GCP, Databricks, GitHub, LinkedIn).

## Estructura del Repositorio

- `agents/`: Definiciones de comportamiento para los agentes (Curador y Copywriter).
- `docs/`: Documentación de la estrategia, sprints y prompts en ambos idiomas.
